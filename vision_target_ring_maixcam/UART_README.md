# UART 视觉数据包说明

## 串口

- 设备：UART0 `/dev/ttyS0`
- 115200 baud，8N1，无流控，3.3 V TTL，共地
- MaixCAM Pro TX A16 接单片机 RX；RX A17 接单片机 TX
- UART0 默认映射 A16/A17，无需额外 pinmap。开机会输出日志，单片机应丢弃启动日志及不符合 `{"seq":...,"items":...}` 格式的行；不要将 `serial ready` 当作视觉程序已就绪。
- 若启用了串口登录终端或其他 maix protocol 应用，需确认其未与本程序同时读写 UART0。打开端口成功不代表没有占用冲突；没有实机信息时不要直接修改 `/boot/uEnv.txt`。
- A16 同时参与启动模式检测，上电时不能被外部电路拉低，否则可能无法启动。
- 官方说明：https://wiki.sipeed.com/maixpy/doc/zh/peripheral/uart.html
- 单片机命令为 `1\n`、`2\n`；视觉结果为单向发送，不要求单片机应答。

## 最小结果包

每个包是 ASCII JSON，末尾为换行符 `\n`，视觉端单向发送，不等待 ACK：

```json
{"seq":42,"items":[[1,-29.4,108.8]]}
```

- `seq`：视觉端 uint32 递增包序号，回绕后从 0 开始。
- `items`：检测到且已通过连续帧确认的对象列表，每项为 `[编号,dx,dy]`。
- `items` 中编号的含义由单片机当前发送的命令决定：命令 `1` 时为颜色序号，命令 `2` 时为靶环序号。
- 模式 1 的编号是颜色序号：红 1、黄 2、蓝 3、绿 4、黑 5、浅蓝 6。
- 模式 2 的编号是靶环序号：1、2、3。
- 模式 1 `dx/dy` 使用物料参考点 `(347.4,132.2)`；模式 2 使用靶环识别中心参考点 `(355.0,178.0)`。单位均为 640x480 图像像素，正值表示向右/向下。
- 屏幕显示中，物料参考点为洋红色十字，靶环参考点为青色十字。
- 靶环模式允许检测框贴近或部分超出图像边缘；设备端优先使用框内轻量暗环估计，估计失败时使用 YOLO 检测中心。只要检测中心连续 3 帧稳定，就发送坐标，适用于部分遮挡或不完整靶环。
- 无可用目标、识别失败或结果过期时发送 `items:[]`，不会沿用上一包坐标。

示例：

```json
{"seq":43,"items":[[1,-47.4,47.8],[3,82.6,15.1]]}
{"seq":44,"items":[]}
```

靶环模型已更新为 `model_9728.mud`/`model_9728.cvimodel`，标签为 `target_1,target_2,target_3`。

说明：MaixCAM 端使用不依赖 OpenCV 的轻量 ROI 暗环估计（`center_source=dark_roi`），用于实时控制；PC 端 `target_ring/center.py` 继续使用多椭圆拟合做离线精度验证。两者都不会使用数字区域单独决定中心，且都要求连续帧确认。
